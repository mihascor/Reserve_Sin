# ADR 003: закрытый read-only веб-интерфейс истории

**Статус:** запланировано.

## Решение

Веб-интерфейс Reserve_Sin будет состоять из статических файлов HTML, CSS и Vanilla JavaScript, которые обслуживает Caddy. Node.js, npm и клиентские фреймворки не используются.

Первой страницей будет `/app/` — read-only таблица истории. Она показывает неотменённые операции активных категорий: дату, категорию, метку, комментарий, приход, расход и признак групповой операции. Операции архивных категорий в эту таблицу не включаются. Правило для операций с архивной меткой будет определено при реализации и закреплено в контракте API.

Доступ к `/app/*` и `/app-api/*` защищается Caddy Basic Auth для одного пользователя. Пароль хранится только в виде криптографического хеша; доступен только HTTPS.

Браузер обращается только к относительным URL `/app-api/*`. Caddy после успешной Basic Auth заменяет клиентский заголовок `Authorization` на внутренний `Bearer` с `RESERVE_SIN_API_TOKEN` и проксирует запрос к Go API на `127.0.0.1:8080`. API-токен не передаётся JavaScript, HTML, логам или ответам браузеру. Маршрут `/api/v1/*` сохраняет существующую Bearer-защиту для Android.

Для веб-истории будет выделен отдельный read-only маршрут Go API, а не изменена семантика существующего `GET /api/v1/transactions`, используемого Android. Он должен поддерживать постраничную выдачу и возвращать только данные, определённые этим решением.

## Обоснование

Статическая страница не требует нового сервера, контейнера или сборочного контура и использует текущую SQLite-базу вместе с Android-приложением. Отдельный маршрут исключает скрытое изменение поведения мобильного клиента. Передача Bearer-токена только между Caddy и локальным Go API не позволяет извлечь его из браузера.

## Следствия

Потребуются статические файлы веб-интерфейса, Caddy-маршруты и защищённая серверная конфигурация Caddy с хешем Basic Auth и API-токеном вне Git. Потребуются тесты фильтрации, пагинации и авторизации, а также проверка адаптивности таблицы на мобильных и desktop-разрешениях. Веб-интерфейс первой версии не создаёт, не изменяет и не отменяет данные.
