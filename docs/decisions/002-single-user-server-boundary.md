# ADR 002: единый личный сервер и Bearer-токен

**Статус:** частично реализовано.

## Решение

Для одного пользователя применяется один постоянный Bearer API-токен. Публичный HTTPS-вход обеспечивает Caddy, а Go REST API доступен только на `127.0.0.1:8080` и работает с SQLite.

## Обоснование

ТЗ исключает регистрацию, логин/пароль, OAuth, JWT, refresh-токены, ролевую модель, микросервисы и Docker для Reserve_Sin. Указанная граница уменьшает число компонентов и не открывает порт API в интернет.

## Следствия

Bearer-проверка API, обязательный токен сервера и защищённое хранение токена Android уже реализованы. Токен должен храниться вне Git и логов, env-файл — с ограниченными правами; API-запросы передаются только по HTTPS. Caddy, systemd и production-конфигурация SQLite пока не добавлены в проект.
