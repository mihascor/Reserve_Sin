# Внешние компоненты

## Статус

Интеграции зависят от окружения развертывания. Production-развёртывание использует Caddy, DuckDNS и существующий AmneziaVPN; их фактические учётные данные и настройки не хранятся в репозитории.

| Компонент | Роль | Граница ответственности |
| --- | --- | --- |
| Caddy | HTTPS, reverse proxy и автоматическое получение/продление TLS-сертификатов для `reserve-sin.duckdns.org`; запланированная Basic Auth и раздача статического веб-интерфейса. | Передаёт запросы локальному Go API; после реализации веб-интерфейса добавляет Bearer-токен только на внутреннем `/app-api/*` proxy. |
| DuckDNS | Домен `reserve-sin.duckdns.org`, указанный как публичный адрес. | Конфигурация DNS не приложена. |
| Android Keystore | Защита API-токена на устройстве. | Не является серверным хранилищем токена. |
| WorkManager | Повторная фоновая синхронизация Android. | Не заменяет серверную идемпотентность. |
| AmneziaVPN | Уже существующий независимый сервис VPS. | Не участвует в Reserve_Sin и не должен изменяться в рамках проекта. |

Банки, выписки, платёжные системы, Firebase как основное хранилище и сторонняя регистрация пользователей в ТЗ не используются.
