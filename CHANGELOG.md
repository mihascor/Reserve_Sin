# Журнал изменений

Все заметные изменения проекта фиксируются в этом файле.

## [Unreleased]

### Добавлено

- Фоновая Android-синхронизация через WorkManager: уникальный запуск при старте приложения, периодическая проверка при доступной сети и повтор неудавшихся запросов с экспоненциальной задержкой.
- Локальная история операций Android: фильтры по периоду, категории, метке, направлению, отменённому и несинхронизированному статусам; группировка batch-операций и экран подробностей.
- Отмена одиночных и групповых операций на Android с локальным статусом `CANCEL_PENDING` и ручной отправкой на сервер.

## [0.4.0] — 2026-08-07

### Изменено

- Android-интерфейс переведён на контрастную тёмную тему; системные панели, карточки, поля ввода, кнопки и диалоги используют единую палитру.
- Действия на главном экране расположены вертикально, чтобы полностью помещаться на узких экранах.
- Действия категории расположены вертикально в правой части карточки и получили контрастную обводку; «Восстановить» переименовано в «Из архива».

### Добавлено

- Удаление ошибочно созданной несинхронизированной категории без операций после подтверждения.
- В документации зафиксирован следующий этап: безопасное развертывание сервера и сквозная проверка синхронизации с тестовыми данными до переноса фактической истории.
- Материалы установки на VPS: systemd-сервис API, service/timer ежедневного резервного копирования, Caddy-конфигурация и скрипт SQLite backup API с проверкой целостности и хранением 14 суток.
- Подтверждённый сценарий Linux для сборки, установки по USB и перезапуска debug APK на подключённом Android-телефоне.

### Исправлено

- Изменение названия, цели или архивности уже синхронизированной категории снова ставит её в очередь и отправляется на сервер через `PATCH` при ручной синхронизации.
- Основные кнопки на главном экране переведены на стандартный Material 3-компонент с фиксированными контрастными цветами; их скругление совпадает с плашкой общей суммы.
- Выбор «Пополнение» или «Списание» теперь всегда помещается в одну строку и явно показывает активный вариант.
- Кнопка выбора категории и её выпадающее меню получили контрастную рамку; меню открывается сразу под кнопкой.
- Совместимость отправки JSON-заголовка с используемой версией Ktor в Android-клиенте синхронизации.
- Сборка Android с `compileSdk 37`, требуемым актуальными `androidx.core` и `androidx.core-ktx`.

## [0.3.0] — 2026-08-06

### Добавлено
- Начальная Android local-first основа: Room-модели, DAO, Repository, HomeViewModel и главный экран с локальной сводкой.
- Локальные экраны управления категориями и создания одиночных и групповых операций; новые операции сохраняются в Room со статусом `PENDING`.
- Команда Go для транзакционного и идемпотентного импорта CSV истории в SQLite.
- Android-экран настройки HTTPS-сервера и API-токена, защищённое хранение токена в Android Keystore и проверка Bearer-подключения через Ktor.
- Уникальный `client_category_id` категорий в SQLite и API для идемпотентного сопоставления офлайн Android-категорий с сервером.
- Ручная отправка локальных категорий и одиночных/групповых операций на сервер с сохранением серверных ID и статусов синхронизации в Room.
- Загрузка и применение серверных категорий, меток и операций через `/api/v1/changes` с сохранением revision Android.

## [0.2.0] — 2026-08-05

### Изменено

- Единица денежных сумм в ТЗ и документации унифицирована: целые рубли; поля базы данных переименованы в `target_amount_rub` и `amount_rub`.
- `GET /health` проверяет доступность SQLite.

### Добавлено

- Централизованное серверное логирование на стандартном `log/slog` с конфигурацией среды, уровней и `request_id`.
- Начальная SQLite-схема, встроенные SQL-миграции и автоматическое применение при запуске Go-сервера.
- REST API для категорий, меток, операций, сводки и синхронизации изменений по revision.
- Bearer-авторизация через обязательную переменную `RESERVE_SIN_API_TOKEN`.

## [0.1.0] — 2026-08-05

### Добавлено

- Начальная структура Android-приложения на Kotlin и Jetpack Compose.
- Начальная структура Go-сервера с маршрутом `GET /health`.
- Конфигурации зависимостей Android и Go.
